三、安装步骤

网络声明

如果无法连接到 GitHub（网络受限、仓库被墙、git clone 失败等），直接使用本地离线方法——用夸克网盘下载 nihaixia-skill.rar，解压后按「通用原则」复制即可，完全不需要 GitHub。

通用原则

  1. 把 nihaixia-skill/ 整个目录复制到你的技能目录，目录名改为 nihaixia
  2. 重启 / 重新加载 agent，让技能元数据生效
  3. 用测试问题验证激活（见第五节）

按平台

平台技能目录命令
Claude Code~/.claude/skills/git clone https://github.com/jangviktor-web/nihaixia.git && cp -r nihaixia/ ~/.claude/skills/nihaixia/
OpenClaw内置openclaw skills install @jangviktor-web/nihaixia
Hermes Agent~/.hermes/skills/ 或 ~/.hermes/profiles/<profile>/skills/复制目录后重启 Hermes
Cursor / Codex / 其他各 agent 的 skills 目录复制目录，参照该 agent 的 skill 安装规范

（离线安装：把夸克网盘下载的 nihaixia-skill/ 解压，按「通用原则」复制即可，不依赖 GitHub。）

四、注册关键要素（★安装后必须核对）

技能能否被激活，取决于以下注册信息。复制后打开 SKILL.md 第一行起检查：

  1. frontmatter 必须完整保留（文件开头的 --- 块）——name 必须为 nihaixia，且目录名也必须是 nihaixia
  2. 注册关键词（触发词）——用户问题中出现触发词，必须激活本技能并以倪海厦视角回答
  3. 路径完整性——确认 modules/、cases/、references/ 与 SKILL.md 同目录存在

frontmatter 长这样（不要精简或改写 description，触发词就在里面，AI 靠它判断何时激活）：

frontmatter 示例--- name: nihaixia description: | 倪海厦（1954-2012）台湾中医师，经方派代表人物，汉唐中医创始人。 ...（多行描述，含触发词和知识库覆盖说明）... ---

注册关键词（触发词）

  • 倪海厦
  • 海厦视角
  • 中医倪海厦
  • 经方思维
  • 倪海厦会怎么看
  • 倪师
  • 以及 description 知识覆盖词：中医、伤寒、金匮、六经辨证、经方 等中医辨证语境

五、安装后验证

重启后测试以下问题，确认技能激活且能检索原文：

验证 1 · 六经辨证
「倪海厦会怎么看失眠？」

应返回六经辨证框架（如黄连阿胶汤证/少阴病），并引用 SKILL.md 行号或模块文件。

验证 2 · 方证对应
「用海厦视角分析桂枝汤证」

应输出太阳病·桂枝汤方证，引用 modules/01_shanghan_sun.md 原文。

验证 3 · 条文引用
「伤寒论里小柴胡汤怎么用？」

应引用条文 + 方剂对比。

六、使用纪律（技能内置规则）

使用纪律 · 四条
检索流程 —— 先查 SKILL.md 关键词索引（关键词→行号映射）→ 用 read_file 按行号读原文 → 索引没有就搜 modules/ → 都没有就如实说「倪海厦讲义中没有涉及此话题」。
不凭记忆回答 —— 知识内容一律以检索到的原文为准。
安全边界 —— 这是参考工具，不是执业医师；用药建议必须提醒用户咨询专业医师；急症建议就医。
辨证路径 —— 先辨六经（望→问→脉→八纲→合病并病→真寒假热），再选方；经方优先，加减有据。

七、常见安装错误

错误后果修复
只复制 SKILL.md技能「激活」但查不到内容补复制 modules/ cases/ references/
目录名不是 nihaixia部分 agent 不识别改目录名
description 被改写/精简触发词丢失，技能不激活恢复原 frontmatter
装完不重启元数据不加载重启 agent
知识库路径写死成本机绝对路径换机器失效本技能是自包含相对路径，无需改路径
