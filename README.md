## 核心架构（改代码前必读）

- **纯静态、全内联、单文件架构**：9 个 HTML 文件互相独立，无框架、无构建、无服务器依赖。每个页面 CSS/JS 全部内联在单个 HTML 里，浏览器直接双击打开就能完整渲染。
- **SITE 常量机制**：每个页面 head 里有 `const SITE = { name: "绝顶赵", latin: "JUEDING ZHAO" }`，配合 `data-site-name` / `data-site-latin` 属性占位。改名字只改 SITE，全页自动跟随。新页面必须保留这个机制。
- **唯一外部依赖**：Google Fonts（Space Grotesk 500/700，仅首页 + 文章页 + 模板使用）。离线时自动回退系统字体，页面不破。工具页刻意零外部请求。
- **图标**：全部用 Lucide 内联 SVG（24×24、stroke 1.75）。**全程零 emoji**——任何新内容禁止出现 emoji 字符。
- **favicon**：data URI 内嵌（黑色圆角方块 + 黄色「赵」字），零请求。

## 如何添加新文章（标准流程）

1. **复制 `文章模板.html`**，重命名放入 `专栏/` 目录。
   - ⚠️ **文件名禁止使用全角冒号「：」和全角问号「？」**——CDN clean URL 和部分内置浏览器会出问题（踩过坑）。用全角括号、句点等安全字符，如 `专栏/我的新文章.html`。
2. **改 `<title>`** 和 SITE 常量保持不动。
3. **文章头部**：标题（空心描边大字，`<span class="accent">` 包几个字可变实心黄）、副标题、`badge-community`（黄色标签，文字可自定义如「社群专享」「核心理论」）、系列标识、日期。
4. **正文**：用模板里的组件，全部在模板正文区有示例——
   - `<p>` 段落、`<h2 class="section-heading">` 章节标题、`<h3 class="sub-heading">` 分节
   - `keyword`（黄色马克笔下划线）/ `highlight`（黄底黑字）
   - `quote-block` 金句卡（黑底黄边）、`highlight-block` 重点卡（黑卡黄边）
   - `qa-block` 问答 / `case-block` 案例 / `framework-block` 框架
   - `ul` 无序列表（黄方块）/ `ol` 编号列表（黄角标 01/02/03）
   - `article-table-wrap` 表格（黄表头硬边，移动端横向滚动）
   - `formula-block` 公式块（黑底黄边，`>` 要写 `&gt;`）
   - `divider` 分隔线、`footer-note` 预告、`promo-block` 锦囊妙计推广
   - 允许/禁止类条款用 Lucide 图标列表，**禁止 emoji**
5. **系列导航**：上一/下一篇硬边卡片；没有就保留 `disabled` 写法。
6. **首页列表**：在 `index.html` 的 `<div class="article-list">` 顶部插入新行（结构照抄现有行），并重排全部 `ar-num` 编号（01/02/03…）。
7. **首页归档**：在 `index.html` 的 `<section id="archive">` 归档区，把新文章加进对应月份的 `.arch-month`（月份卡片，结构照抄现有行：日期 + 标题 + 黄色标签）。没有对应月份就新建一个 `.arch-month` 卡片插到归档列表顶部，并记得重排月份顺序（新月份在前）与篇数标签。
8. **提交推送**：commit + push，Cloudflare 自动部署。

## 踩过的坑（务必记住）

1. **文章页正文不能依赖 JS 才显示**：v4 曾用 IntersectionObserver 触发正文淡入，长文章首屏触发阈值不足 → 正文全透明（线上事故）。修复后正文默认直接可见，只保留 hero 标题动画。**新文章页不要给正文加 reveal**。
2. **hero 视差层导致元素重叠**：滚动时不同速度的层会互相追叠（圆章压按钮、标题盖 CTA）。已停用 hero 全部视差。**不要恢复 hero 视差**。
3. **文件名的全角冒号/问号有 CDN 隐患**（见上）。
4. **Cloudflare 会对 HTML 注入 JSD 追踪脚本**（隐藏链接 + iframe），属正常现象，不是页面 bug。
5. **Cloudflare 会把 `.html` 请求 308 重定向成 clean URL**（去后缀），部署后线上地址和本地文件名不完全一样，属正常。
6. **`plan.md` 在 .gitignore 里**（计划文档不入库）；README 必须入库。

## 协作约定（重要）

- **AI 只改代码，站长负责验收**：AI 不跑截图、Lighthouse、浏览器审查、http server。改完交付，站长在浏览器/生产环境自行验证。
- **不要安装任何浏览器相关工具**（puppeteer/playwright/chromium 等），站长明确禁止。
- 每次改动：改完 → 自查（JS 语法 node 检查、标签闭合、emoji 零残留、SITE 占位完整）→ commit → push。
- 工具页（show/drive-test/test）的**交互 JS 零改动**原则：只允许换视觉壳（CSS/导航/页脚）。
- 文章正文内容一字不改（除非站长明确要求）。
- 验收通过前不 commit？——不，当前惯例是：改完自查通过即可提交推送，站长在生产环境验收，不满意再改再推。
