Markdown 写作语法

一、元信息（表单填写，保存时写入文件头部）

标题 / 日期 / 黄色标签 / 系列 / 副标题 / 首页摘要 / 上一篇下一篇。标题里用 **文字** 包住的部分会变成实心黄色。

二、基础语法

写法效果
## 章节标题大章节标题（黄条下划线）
### 分节小节标题
**加粗**加粗
==高亮==黄底黑字
++关键词++黄色马克笔下划线
`代码`行内代码
[文字](链接)链接
![描述](图片地址)图片
- 项目 / 1. 项目无序 / 编号列表（缩进两个空格可嵌套）
| 列一 | 列二 | 加第二行 |---|---|表格（黄表头）
单独一行 ---分隔线

三、站点专属卡片（工具栏可直接插入）

## 章节标题

正文段落。

> 一句话金句（自动变成黑底黄边金句卡）

::: qa Q1 · 这一节回答的问题
把读者的问题写在这里。
把回答写在这里，可以有多个段落。
:::

::: case 举个例子
案例内容写在这里。
:::

::: framework 框架名
- **要点一** —— 解释要点一
- **要点二** —— 解释要点二
:::

::: highlight
需要重点强调的内容，黑底黄边卡片。
:::

::: formula 公式名
公式内容 = 变量一 + 变量二
其中：
- 变量一：解释
:::

::: note 预告
下一期写什么，在这里预告。
:::

五、其他

  • 正文里可以直接写 HTML（比如带图标的条款列表 <svg> 会原样保留）。
  • 保存：Ctrl+S。发布会生成 专栏/xxx.html 并自动更新首页列表与归档。
  • 文件名自动去掉全角冒号「：」和问号「？」（CDN 踩坑约定），可在表单里手动指定。
